CẤU HÌNH GITHUB DATABASE

Biến kho GitHub của bạn thành cơ sở dữ liệu đám mây. Mỗi khi bạn thêm, sửa, xóa bài, website sẽ tự động commit và lưu trữ trực tiếp vào repository GitHub.

Token có quyền repo để đọc và ghi file. Token chỉ lưu an toàn trên trình duyệt của bạn.
