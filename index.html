Đồng Bộ Lên GitHub Pages / Netlify

Cách đưa bài viết mới lên cho toàn thế giới đọc:

  1. Bấm nút "Tải file posts.json" bên dưới về máy của bạn.
  2. Vào repository GitHub của blog (nơi chứa file index.html).
  3. Kéo thả hoặc upload đè file posts.json vừa tải vào cùng thư mục với index.html rồi chọn Commit changes.
  4. GitHub Pages / Netlify sẽ tự động tải lại và độc giả khắp nơi sẽ thấy bài viết mới của bạn ngay lập tức!
